# Contributing

Please keep contributions focused on independently implemented interoperability.

Do not submit:

- APKs or extracted vendor binaries
- decompiled vendor source code
- disassembly dumps
- copied proprietary implementation code

Packet captures should be sanitized before publication if they contain
unrelated local traffic.

When adding support for another camera revision, document:

- camera identification/status string
- network addresses and ports
- confirmed command IDs
- video framing differences
- orientation metadata differences
