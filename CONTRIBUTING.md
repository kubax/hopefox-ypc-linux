# Contributing

Contributions and test results from related Soulear/YPC camera revisions are welcome.

Useful reports include:

- camera identification/status string
- network addresses and ports
- confirmed command IDs
- video framing differences
- orientation metadata differences
- whether LED control behaves differently

Packet captures should be sanitized before publication if they contain unrelated
local traffic.

The project is intentionally experimental and has been developed largely through
trial and error plus AI-assisted analysis/coding, so reproducible observations are
particularly valuable.
